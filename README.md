Fortune Cookie Wisdom for Developers — one original fortune-cookie line for a software developer, at most 120 characters. A pure-stdlib Python program that writes the line to `/output/entry.txt`, guarded by a validator that refuses anything failing the scorer's gate (1–120 characters, single line, not only white space, valid UTF-8).

## Run it

```sh
python3 main.py
```
